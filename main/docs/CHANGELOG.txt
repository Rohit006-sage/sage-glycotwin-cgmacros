2026-10-05: Phase 1 metric provenance

The first README reported the original unlimited-forward-fill run (saved in
`data/processed/baseline_v1/`). Phase 1 changed dynamic sensor feature
construction to allow values to carry forward for no more than 30 minutes,
using pandas' time tolerance. This prevents stale CGM, heart-rate, and activity
measurements crossing long recording gaps. The participant folds, labels,
features, and estimator settings were otherwise unchanged. Because predictions
are produced by refitting models on changed predictor matrices, ranking and
calibration metrics can move even though sample/event counts remain 45,447 and
2,845.

Fused gradient boosting changed from pooled ROC-AUC 0.883273 to 0.882377 and
sample-weighted fold-mean PR-AUC 0.426840 to 0.425223. Healthy-range PR-AUC
changed from 0.038060 to 0.035951. These small shifts reflect changed feature
availability at outage-adjacent samples and refitted predictions; they are not
a new label set or fold assignment. Exact changes also occurred in other
models. Some appeared unchanged only after rounding: sensor-only logistic
regression fold-mean PR-AUC moved 0.338796 to 0.343969; sensor-only gradient
boosting moved 0.408770 to 0.412786; fused logistic regression moved 0.273911
to 0.272586. Constant-prevalence and persistence metrics were exactly
unchanged because they do not use the forward-filled feature set. The README's
older table used coarser rounded values and therefore obscured several of
these differences.

Healthy-range PR-AUC depends on a small event set: 106 positive timestamps,
from only two of the 15 participants. This small denominator also makes a
few ranking changes visible in the subgroup average-precision score.

Phase 1 preserved its run under `data/processed/` at the time Phase 2 was
started. Phase 2 artifacts are stored separately so both prior evaluations
remain available for review.
2026-10-05: Phase 2 nested grouped evaluation

Phase 2 evaluation is isolated under data/processed/phase2/. The earlier
unlimited-forward-fill baseline remains under data/processed/baseline_v1/ and
Phase 1 remains under data/processed/phase1/. The first README's claim that
other model scores were unchanged was not exact: several learned-model metrics
also moved after the 30-minute maximum-age feature change; rounded tables hid
small deltas. Constant-prevalence and persistence baselines were exactly
unchanged. The reasons and exact Phase 1 deltas are documented above.

Evaluation design: five outer StratifiedGroupKFold folds by participant, with
three inner grouped folds per outer training set. Six fixed HGB parameter
combinations cover learning_rate 0.03-0.10, max_iter 120-500, max_leaf_nodes
7-31, min_samples_leaf 50-300, and l2_regularization 0-10. Inner-fold average
precision selects classifier settings; max_iter is selected using participant
validation (no row-random sklearn early stopping). Regression settings are
selected by inner-fold MAE. Outer folds provide the reported held-out scores.
Thresholds for an 80% training precision target come from inner OOF scores and
are applied unchanged to outer test participants. Platt scaling is fitted on
inner OOF predictions in each outer-training set. Ablations compare sensor-only
versus fused HGB, full/reduced-EHR logistic regression, and 15/30/60-minute
forward-fill ages; feature-age ablations reuse the fused model's selected outer
fold settings rather than being separately retuned. Continuous glucose MAE and
RMSE cover every participant/sample. Pooled participant bootstrap intervals
use 2,000 cluster resamples.

Main nested fused HGB results: pooled PR-AUC 0.38850, ROC-AUC 0.87765,
Brier 0.04672; equal-weight fold-macro PR-AUC 0.41566 and ROC-AUC 0.87444;
sample-weighted fold mean PR-AUC 0.41634 and ROC-AUC 0.87537. The selected
80%-precision policy emitted only seven positive alerts and achieved 0.25%
pooled outer-OOF recall. Regressor pooled MAE/RMSE were 20.46/29.43 mg/dL;
equal-participant macro MAE/RMSE were 20.59/27.05 mg/dL. See
`data/processed/phase2/phase2_metrics.json` and
`data/processed/phase2/phase2_oof_predictions.csv` for detailed fold and
subgroup results. Calibration and fold outputs are based on this single
participant cohort and do not constitute external validation.

Observed runtime on the current Windows machine was approximately four minutes
for the nested model fits and data preparation, plus about thirty seconds for
the 2,000-replicate participant bootstrap. Timing is machine-dependent.

Expanded nested evaluation and chronological analysis (2026-10-05)
-------------------------------------------------------------------
Used the full cohort and added 30-, 60-, and 120-minute binary targets and
continuous regression targets. Added rolling glucose statistics, minutes above
140/180 mg/dL and observation coverage in the preceding hour, meal timing, and
a linear-decay three-hour carbohydrate-on-board proxy. The proxy is a feature
heuristic, not a validated physiological model. Feature-group ablations reuse
the primary settings and are not retuned.

Widened the tested HGB candidates to learning_rate 0.02-0.10, max_iter
300-1,000, max_leaf_nodes 3-31, min_samples_leaf 50-1,000, and L2 0-10.
Classifier choices use only inner participant-grouped average precision;
regression choices use inner participant-grouped MAE. A first repeated-CV
attempt labeled five identical StratifiedGroupKFold participant assignments
with different seeds. Those results were rejected. The final repeated primary
evaluation uses five distinct seeded, participant-level balanced assignments;
the five pooled/macro score ranges are in docs/results/aggregate_metrics.json.
Several selected settings still hit tested boundaries (see README and metrics).

Added nested HGB runs using five baseline EHR variables and HbA1c alone, each
fused with sensor features. Because these comparisons were added after earlier
results were observed, selecting a preferred variant is exploratory. Replaced
the earlier high-precision operating point with training-only top 1%, 5%, and
10% alert-budget thresholds plus a training 40%-precision target, applied
unchanged to held-out participants.

Added chronological within-person evaluation: first 70% of each person's
timeline for adaptation/training and final 30% for testing; classification
requires at least ten positive labels in each segment, while regression covers
all 45 participants. Compared population-only, population plus early-person
adaptation, and person-only models. Detailed sample-level outputs stay local
under the git-ignored data/processed/revised_full directory. Public docs/results
contains aggregate-only results; docs/figures contains aggregate SVG plots.
Do not distribute per-sample derived predictions.
